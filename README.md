# Dorm Competition Bot

Telegram-бот для конкурса среди студентов общежития.

## Возможности

- заполнение нормативов за сегодня;
- заполнение за любую дату от даты старта конкурса до текущего дня;
- мгновенное сохранение каждого изменения;
- рейтинг топ-10 с призами;
- имена соперников скрыты, пользователь видит только себя;
- минимальный мусор в чате: интерфейс обновляется через edit_message_text, произвольные пользовательские сообщения удаляются;
- простая команда `/admin` для администратора.

## Баллы

- Утренний совместный спорт — 1
- Ночной совместный спорт — 1
- Совместный завтрак — 1
- Совместный ужин — 1
- Приготовил завтрак — 0.5
- Приготовил ужин — 0.5
- Проведение рассказа — 1
- Прослушивание рассказа — 1
- Академический час — 1

Приготовление завтрака + ужина суммарно дает 1 балл.

## 1. Создание Supabase

Создайте проект Supabase и откройте SQL Editor.

Сначала выполните содержимое `schema.sql`.

После этого добавьте участников вручную через Table Editor или подготовьте `seed_users.sql`.

Для каждого пользователя нужен его числовой Telegram ID.

## 2. Настройка переменных

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните значения:

```env
BOT_TOKEN=...
SUPABASE_URL=...
SUPABASE_KEY=...
ADMIN_TELEGRAM_ID=...
TIMEZONE=Europe/Moscow
COMPETITION_START=2026-09-01
```

Для серверного бота предпочтительнее использовать `service_role` key и никогда не публиковать `.env` в GitHub.

## 3. Локальный запуск

Python 3.11+ рекомендуется.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## 4. Railway

1. Создайте GitHub-репозиторий и загрузите эти файлы.
2. В Railway создайте New Project → Deploy from GitHub Repo.
3. Добавьте Environment Variables из `.env`.
4. Start command:

```bash
python bot.py
```

## Добавление пользователей

Пример SQL:

```sql
insert into public.bot_users (telegram_id, telegram_username, full_name)
values
  (111111111, 'ivanov', 'Иван Иванов'),
  (222222222, 'petrov', 'Петр Петров')
on conflict (telegram_id) do update
set telegram_username = excluded.telegram_username,
    full_name = excluded.full_name,
    is_active = true;
```

## Важное правило рейтинга

Сейчас при одинаковых баллах технический порядок определяется именем пользователя по алфавиту. Это только tie-break для стабильного отображения.

Если вы хотите делить призы между участниками с одинаковыми баллами, эту механику лучше добавить отдельно до финального расчета денежных выплат.
