DAILY REMINDERS UPDATE

1. В Supabase -> SQL Editor выполните файл:
   schema_reminders.sql

2. В GitHub замените:
   bot.py
   requirements.txt

3. Railway автоматически задеплоит изменения.

4. В Railway Variables можно добавить:
   REMINDER_HOUR=22
   REMINDER_MINUTE=0
   REMINDER_TTL_HOURS=2

Если переменные не добавлять, значения по умолчанию:
- уведомление в 22:00
- удаление уведомления через 2 часа

Важно:
TIMEZONE должен быть Europe/Moscow, если уведомления нужны в 22:00 по Москве.

Как работает:
- 22:00 -> приходит уведомление.
- Нажатие "Заполнить нормативы" -> уведомление удаляется, открывается текущий день.
- Если пользователь не нажал -> уведомление автоматически удалится через 2 часа.
