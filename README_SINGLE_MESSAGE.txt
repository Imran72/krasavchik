Что изменилось:
- у каждого пользователя хранится last_ui_message_id;
- перед отправкой нового экрана бот удаляет предыдущий;
- в 22:00 старое меню удаляется и вместо него приходит напоминание;
- если нажать "Заполнить нормативы", напоминание удаляется и появляется экран дня;
- если не нажать, напоминание удаляется автоматически через REMINDER_TTL_HOURS;
- /start тоже удаляет предыдущий экран перед созданием нового.

Важно:
Старые сообщения, которые уже накопились ДО этого обновления, бот не знает по message_id и автоматически все их задним числом удалить не сможет.
После установки обновления новые сообщения больше копиться не будут.
