РАЗОВОЕ ДОЗАПОЛНЕНИЕ ДО 00:00 ПО МОСКВЕ

Файлы:
- bot.py — основной бот
- broadcast_refill.py — разовая рассылка
- requirements.txt

ПОРЯДОК:

1. Сначала заменить bot.py в GitHub.
2. Дождаться, пока Railway задеплоит новый bot.py.

3. Затем добавить broadcast_refill.py в GitHub.

4. В Railway временно поменять Start Command:
   python broadcast_refill.py

5. Сделать Redeploy.
   Скрипт:
   - удалит текущее отслеживаемое сообщение;
   - отправит уведомление;
   - добавит кнопку "Понял, принял".

6. После того как рассылка выполнится, вернуть Start Command:
   python bot.py

7. Снова Redeploy.

До 00:00 по Москве:
- можно выбрать любую дату с 01.09.2026 по текущий день;
- можно редактировать нормативы за эту дату.

После 00:00:
- автоматически снова доступны только текущий и предыдущий день;
- попытки использовать старые callback-кнопки на старые даты блокируются.
