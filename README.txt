ТОЧНАЯ ЛОГИКА БОТА

Обычное состояние:
- в чате одно сообщение;
- под ним 3 кнопки:
  1. Заполнить текущий день
  2. Заполнить предыдущий день
  3. Рейтинг

Ограничение:
- редактировать можно только текущий и предыдущий день;
- более старые callback-кнопки блокируются.

Напоминание:
- ежедневно в 22:00;
- базовое сообщение удаляется;
- вместо него появляется отдельное напоминание;
- кнопка: "Понял, согласен".

Если нажать:
- напоминание удаляется;
- создаётся базовое сообщение с тремя кнопками.

Если не нажать:
- через 2 часа напоминание удаляется;
- автоматически создаётся базовое сообщение с тремя кнопками.

Установка:
1. Выполнить schema_single_message.sql в Supabase SQL Editor.
2. Заменить bot.py в GitHub.
3. Заменить requirements.txt при необходимости.
4. Дождаться redeploy Railway.

Railway Variables:
TIMEZONE=Europe/Moscow
REMINDER_HOUR=22
REMINDER_MINUTE=0
REMINDER_TTL_HOURS=2

Важно:
старые накопившиеся сообщения, созданные до внедрения last_ui_message_id,
бот не умеет обнаружить через Telegram Bot API. Их нужно один раз удалить вручную.
После этого новая версия держит только одно актуальное сообщение.
