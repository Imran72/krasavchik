ОБЫЧНЫЙ РЕЖИМ: ТОЛЬКО СЕГОДНЯ + ВЧЕРА

Что работает:
- в чате одно актуальное сообщение;
- 3 кнопки:
  1. Заполнить текущий день
  2. Заполнить предыдущий день
  3. Рейтинг
- любые более старые даты блокируются;
- старые кнопки от временного дозаполнения тоже блокируются;
- ежедневное напоминание остаётся;
- через 2 часа напоминание удаляется и возвращается базовое меню.

Установка:
1. Заменить bot.py в GitHub.
2. Railway Start Command должен быть:
   python bot.py
3. Сделать Redeploy.

SQL менять не нужно.
